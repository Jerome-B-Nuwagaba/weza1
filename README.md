# WEZA — Intelligent Financial Marketplace & Opportunity Network

> **Customer:** Tell WEZA what financing you need. · **Institution:** Tell WEZA what customers you want.
> **WEZA:** Understand. Qualify. Match. Route. Track. Learn.

WEZA connects customer financial demand with the products, eligibility, appetite and capacity of participating financial institutions. It requires **no integration with institutional core systems**. WEZA creates access; financial institutions make the credit decision.
